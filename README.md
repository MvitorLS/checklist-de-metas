# 🎯 MetaCheck — Gestão de Metas Diárias, Mensais e Anuais

> **Aplicativo Mobile-First para Acompanhamento e Check-off de Metas Pessoais.**

---

## 📱 Visão Geral
O **MetaCheck** é um aplicativo focado na experiência mobile para gerenciar metas em três horizontes de tempo:
1. **Diárias:** Hábitos com check-off rápido, dias seguidos (*streaks*) e cálculo da taxa de conclusão do dia.
2. **Mensais:** Objetivos de médio prazo divididos em etapas/subtarefas dinâmicas com progresso incremental (0–100%).
3. **Anuais:** Metas estratégicas de longo prazo com visão consolidada e acompanhamento de prazos.

---

## 🛠️ Tecnologias Utilizadas
* **Frontend Mobile-First:** React 19 + TypeScript + Vite
* **Ícones:** Lucide React
* **Feedback Visual:** Canvas Confetti (efeito de celebração ao atingir metas)
* **Persistência:** LocalStorage com sincronização reativa
* **Design System & Figma:** Especificação completa disponível em [`FIGMA_DESIGN_SYSTEM.md`](./FIGMA_DESIGN_SYSTEM.md)

---

## 🚀 Como Rodar Localmente
```bash
npm install
npm run dev
```
Acesse em: **`http://localhost:5174`** (utilize o modo de dispositivo móvel no DevTools do navegador para melhor experiência).
